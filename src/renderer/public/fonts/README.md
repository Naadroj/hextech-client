# Polices officielles (optionnelles)

Dépose ici, au format **.woff2**, les polices Riot si tu possèdes une licence
ou pour un usage strictement personnel :

- `BeaufortforLOL-Bold.woff2`
- `BeaufortforLOL-Heavy.woff2`
- `Spiegel-Regular.woff2`
- `Spiegel-SemiBold.woff2`

Elles sont chargées automatiquement (voir `src/renderer/styles/fonts.css`) et
priment sur les substituts libres **Cinzel** / **Barlow**. Sans ces fichiers,
l'application utilise les substituts — aucune erreur.

Ces polices ne sont pas versionnées dans le dépôt.
